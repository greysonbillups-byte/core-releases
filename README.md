# CORE

**Broadcast control for esports — drive OBS and every on-screen graphic from one window.**

CORE runs your show from a second monitor: scores, timers, timeouts, rosters, brackets, map veto and replays, all pushed live to your overlays the moment you change them. Connect it to OBS once and it builds your entire scene collection for you, each scene already wired to the right graphic.

This repository hosts the downloads. The source is private.

---

## Download

**[Download the latest build →](../../releases)**

Grab `CORE-Setup-<version>.exe` from the newest release and run it. CORE updates itself after that, so this is the only manual download you need.

### Requirements

- Windows 10 or 11
- OBS Studio 28 or newer, with the WebSocket server enabled (Tools → WebSocket Server Settings)

---

## Supported games

Dedicated scoreboards for **Valorant**, **Counter-Strike 2**, **Overwatch** and **Marvel Rivals**, plus built-in support for **League of Legends**, **Rocket League**, **Call of Duty**, **Rainbow Six Siege** and **Deadlock** — and a generic board for anything else.

Single elimination, double elimination and round robin brackets feed results straight back from Match Control.

## Licensing

CORE is free to use. The free tier covers two schools, four teams and one bracket at a time — enough to run a real head-to-head — with every overlay, map veto, replay capture and the OBS scene builder included.

Paid tiers remove the limits and add overlay customisation, custom hotkeys, your own overlay imports and custom games. Licences are available annually or per semester.
